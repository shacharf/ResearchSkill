---
name: rs-save
description: Save an unfinished or completed research discussion and a compact resume before switching or ending a session.---

Read `rsagent status --json` to locate the active thread. Without an active thread, obtain/create the user's intended thread; do not guess from timestamps. Edit that thread's Research record coherently by subtopic. Preserve evidence locations, reasoning, examples, equations, confidence, accepted/rejected/deferred ideas and their reasons. Add dated checkpoints when understanding changes and retain superseded reasoning.
Update the designated Compact resume: guiding question, current understanding with confirmation/confidence, immediate focus, next step, and essential evidence links. Keep it within the documented default limit of 5000 characters. Update Project brief in project_overview.md only when shared goal/assumptions/user-confirmed conclusions change, within 3000 characters. Preserve generated navigation, existing prose, quoted IDs, and source note bodies. Do not turn suggestions into confirmed conclusions or write paper.md.
Run `rsagent checkpoint` after file edits to regenerate derived navigation/bibliography, validate and persist pending lexical/semantic indexing. Resolve validation issues relevant to the checkpoint without rewriting unrelated prose. Confirm the saved thread and next step briefly, and disclose pending/failed indexing. A Markdown checkpoint and persisted queue permit optional host chat clearing even while background indexing remains pending. Never clear chat before successful persistence.

Paper summaries: for every registered paper discussed in this conversation, run `rsagent paper discuss REF` if it is still `x`-prefixed, then create or update its summary with `rsagent paper summary REF` (text on standard input) using the rs-paper format (read the current one with `rsagent paper show REF` and the saved overview with `rsagent paper show REF --overview`; where the discussion clarified or corrected the overview, the summary uses the clarified version; revise rather than duplicate). Do this before every switch, pause or close, then run `rsagent checkpoint`.
